# ADR 0005: Project stages expand in the main sidebar

Accepted from the user's explicit direction, 2026-10-22. Supersedes only the secondary stage sidebar in ADR 0004.

Project Management expands in the existing main sidebar to reveal the 11 stages. Each stage links to the same scoped pipeline route with its stage query. The page contains only that stage's customers, search and actions at full width. No second stage navigation rail. Direct stage links auto-expand the main-menu group and highlight the selected stage. Existing confirmed next-stage movement and customer operations remain unchanged. Loan and subsidy remain plain links.

Verify expansion/collapse, all 11 links, selected-stage highlight, direct links, full-width page and confirmation cancellation without changing live data.
