# ADR 0008: Generic Solar CRM branding throughout the demo

Accepted from user instruction, 2026-10-22. Supersedes ADR 0007's decision to retain company branding in demo document presentation.

Use Solar CRM in demo screens, generated-document letterheads, proposal terms, public signing pages, messages, procurement PDFs and deploy labels. Remove the unused former logo and company-specific public contact details from the demo defaults. Normalize legacy company wording when rendering saved proposal terms; preserve the underlying signed/customer records. Existing authentication identities and storage/session keys remain compatible and are not renamed as part of a visual branding change.
