## Bugs found (fix first)

1. **Call button icon is invisible.** The phone icon in the customer header renders 4px wide (desktop and phone), so the button looks empty.
   `app/src/pages/Record.jsx:38` + `.workspace-actions .btn` padding in `app/src/styles.css:1447`.
2. **Quotation silently changes system size.** Customer is 3.3 kWp, quotation opens at 3 kWp because only whole sizes 2–10 exist
   (`nearestPackage`, `app/src/docs/proposal/settings.js:82`). 3.3 / 4.4 / 5.5 kWp (550 W panels) are common sizes.
3. **Three different "status" stories for one customer** (Nikita Rathod, CRN-2026-0149):
   Today = "Follow up on the quotation on WhatsApp · 1 day late"; search = "Waiting for customer to approve quotation since 3 Nov (4 days)";
   record = "0 days in stage · Prepare quotation". Staff will not know which to believe.
4. **"Active customers 0" while loading** on Customers, before the list arrives. Looks like data is lost for a second.
5. Quotation prices fall back to `PLACEHOLDER_PRICES` when package prices are not set — check the client's real prices are saved before any demo.

## Intuitiveness improvements (biggest impact first)

1. **Shorten the menu.** ~19 sidebar links + an 11-stage sub-menu. Group into 5: Today, Customers, Documents, Money, Team (+ Settings).
   Move Name check, Activity log, Trash, Completed under the pages they belong to.
2. **One "next step" rule everywhere.** Generate the sentence once in `api.js` and show the same text on Today, search, list and record.
3. **"Prepare quotation" should open the quotation maker directly**, not the Documents tab with a second button.
4. **Add a WhatsApp button** next to Call on every customer (wa.me link with a ready message). Quotations and follow-ups already happen on WhatsApp.
5. **Denser customer list** (table view option, 12–15 rows per screen) for office staff who scan many customers.
6. **Fewer stages for the client's view.** 11 stages + "Project journey" + "Current work" is three progress ideas at once. Keep 11 internally; show 6 simple milestones on top.
7. **Hindi / Gujarati labels** for partner and field screens (user requirement from earlier sessions; not started).
8. **Phone record header:** put Call / WhatsApp / Next stage in one row, move "Current stage" and "More" into one menu.
9. Remove demo signals before showing the client: "This browser only", "Demo prototype: no password".
